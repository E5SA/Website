1. Contact Form

Customer fills out name, email, mobile & message on contact.html and submits the form.

2. API Gateway

An AWS HTTP API receives the POST request and routes it to the Lambda function. Configured in terraform/main.tf or aws/sam.yaml.

3. AWS Lambda

The lambda/handler.js function parses the form data and calls the Telegram Bot API to send a formatted message.

4. Telegram Notification

You receive an instant message in your Telegram chat with the customer's details. Requires TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID.

5. CloudWatch Alarm

Monitors Lambda invocations. If more than 100 calls occur in 5 minutes, it triggers an alert to prevent abuse.

6. SNS Email Alert

CloudWatch sends an email via SNS to alarm_email when thresholds are breached (spam or cost spikes).
